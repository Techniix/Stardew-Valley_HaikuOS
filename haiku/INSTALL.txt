Stardew Valley for Haiku (x86_64) - install
===========================================

This package contains no game files. You need to own Stardew Valley 1.6
(Steam, or the Windows build from GOG).

Quick start (Terminal, in this folder):

    ./setup.sh

That installs the needed HaikuPorts packages, installs .NET for Haiku into
./dotnet, builds the native shims, offers to download the game from Steam
(you log in with your own account; password and Steam Guard code go straight
to DepotDownloader and are never stored), and adds a Deskbar menu entry.

Then start the game from the Deskbar, or:

    ./StardewValley.sh

The first launch patches the game files for Haiku. Output goes to log.txt.

Other commands:
    ./get-game-steam.sh           download/update the game from Steam
    ./get-game-steam.sh --qr      same, logging in by QR code (Steam mobile app)
    SDV_MAX_DOWNLOADS=2 ./get-game-steam.sh   fewer parallel downloads if it stalls
    SDV_FORCE_PATCH=1 ./StardewValley.sh      re-patch the game files
    SDV_VANILLA=1 ./StardewValley.sh          play without mods
    SDV_RESTART_MEDIA=1 ./StardewValley.sh    restart media services first
    SDV_NO_AUDIO=1 ./StardewValley.sh         play without sound

If the game crashes as it starts (debug report mentions
BTimeSource::GetTime), that's a Haiku media kit bug. Terminate it in the
debugger; the launcher then offers to restart the media services and retry,
or to play without sound.

If a download stops progressing, it's restarted automatically after 3 minutes
and resumes where it left off.

Mods: unzip SMAPI mods into Mods/ (each in its own folder with a
manifest.json). The launcher starts SMAPI automatically when mods are present.

Multiplayer: Steam friends/invite codes need the Steam or GOG Galaxy client,
which don't exist on Haiku. Use direct IP instead: Co-op > Join > Join LAN
Game and enter the host's IP. To host, keep "Accept IP connections" on in
Options and forward UDP port 24642 for internet play.

Logs: log.txt and logs/exceptions.txt here; SMAPI: ~/.config/StardewValley/ErrorLogs/SMAPI-latest.txt
Saves: ~/.config/StardewValley/Saves

GOG or copied files: put the contents of your Stardew Valley folder (the one
containing "Stardew Valley.dll") into gamedata/ and run ./setup.sh --no-game.
