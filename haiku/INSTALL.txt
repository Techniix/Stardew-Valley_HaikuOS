Stardew Valley for Haiku (x86_64) - install
===========================================

This package contains no game files. You need to own Stardew Valley 1.6
(Steam, or the Windows build from GOG).

Quick start (Terminal, in this folder):

    ./setup.sh

That installs the needed HaikuPorts packages, installs .NET for Haiku into
./dotnet, builds the native shims, offers to download the game from Steam
(you log in with your own account; password and Steam Guard code go straight
to DepotDownloader and are never stored), and adds a Deskbar menu entry.

Then start the game from the Deskbar, or:

    ./StardewValley.sh

The first launch patches the game files for Haiku. Output goes to log.txt.

Other commands:
    ./get-game-steam.sh           download/update the game from Steam
    ./get-game-steam.sh --qr      same, logging in by QR code (Steam mobile app)
    SDV_FORCE_PATCH=1 ./StardewValley.sh   re-patch the game files

GOG or copied files: put the contents of your Stardew Valley folder (the one
containing "Stardew Valley.dll") into gamedata/ and run ./setup.sh --no-game.
